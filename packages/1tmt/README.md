# 1tmt/ — product Vue islands

## Summary

Local product UI that is not part of the upstream Harness React shell. Pages are Vue 3 + Element Plus (MIT) islands; Cordis React plugins only mount them and pass bridges. Presentation contracts for the surrounding Web shell live in the [Web Client](../../docs/subsystems/web-client.md) subsystem.
